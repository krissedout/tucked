# Tucked

A Vencord theme for people who live in their DMs. It tucks the server list behind the left edge of the window and clears out Nitro, Shop and Quests.

It only adds behaviour to Discord's own UI and leaves your colours alone, so it sits happily on top of whatever theme you already use.

## Install

In Discord or Vesktop, open Settings, go to Vencord's Themes page, and paste this into the Online Themes tab:

```
https://raw.githubusercontent.com/krissedout/tucked/main/tucked.theme.css
```

## Getting to your servers

Move your mouse to the far left edge of the window and the server list slides out. It tucks away again when you leave. Discord's Ctrl+K switcher and Ctrl+Alt+Up/Down still work as usual, and tabbing into the list opens it too.

It's Discord's real server list, so folders, unread pills, right-click menus and drag and drop all keep working. When you have a mention, a small red marker shows on the left edge.

To make the list wider, drag its bottom-right corner. The width resets when Discord reloads.

## What gets removed

- Nitro, Shop and Quests in the DM list
- The gift button in the chat bar
- The Get Nitro bar in the emoji picker
- Nitro, Server Boost and Gift Inventory in Settings

Subscriptions and Billing stay, so you can still manage anything you pay for.

## Known issues

- The gift button is only hidden when Discord is set to English.
- The DM list has a little empty space at the bottom where the removed rows used to be.

Discord updates can rename the classes this relies on. If something stops working, open an issue.
